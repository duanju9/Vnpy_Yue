与 Cursor 的关系：
  仓库内为 SKILL.md 文本，可直接阅读；与 Cursor 自带「Skills」格式理念相近。
  若要挂到 Cursor 全局技能，可复制 SKILL.md 到个人 skills 目录并按 Cursor 文档配置。
