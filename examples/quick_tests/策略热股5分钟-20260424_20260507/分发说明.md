# 本包是什么、谁能看懂

本文件夹是一份 **「研究批次的交付物」**：**中文说明** + **跑批数字备忘** + **股票池 CSV** + **`源码/` 内 Python 快照** + **`产物/` 内带前缀的 xlsx**（若已跑 `本包回测_THS三连跑.py`）。  
适合给 **同事 / 合作方 / 未来的自己** 快速理解：**测了什么票、什么区间、什么规则、结果大概多少、指标怎么读、源码长什么样**。

---

## 本包 **不包含**（需另备或说明）

| 内容 | 说明 |
|------|------|
| **与仓库完全一致的开发迭代** | 仍以仓库 `examples/quick_tests/` 下未拷贝文件为准；本包 `源码/` 为 **快照**，可能滞后于主分支。 |
| **仓库默认 output** | 本包优先使用 **`产物/`** 下 `策略热股5m交付_THS20260424-0707_*.xlsx`；与仓库 `output/批量人气_*.xlsx` 区分。 |
| **miniQMT / xtquant** | 复现回测需收件人本机已安装并可用；纯读文档则不需要。 |

## 建议阅读顺序（给外人）

1. **`说明与结论.md`** — 数据定义、回测结果表、口径、结论与改进方向。  
2. **`整体策略展示与打分.md`**（若已生成）— **全池区间涨跌**、策略截面与 **0–100 打分**（热股波动 vs 规则兑现的对照）。生成方式见 `说明与结论.md` 第二节末。  
3. **`跑批记录_交付重跑_20260507_233707.md`**（若存在）— 本包 `产物/` 三连跑与 **新 CSV 文件名** 速查；旧版见 `跑批记录_20260507.md`。  
4. **`源码/README.md`** — 快照列表及 **为何要用 `本包回测_THS三连跑.py`**。  
5. **`测试成分股/`** — 含 `ths_hot_THS20260424-0707_交付重跑_20260508.csv`（交付重跑用名）及原 `ths_hot_top100_*.csv`。

## 若对方 **有完整 Vnpy_Yue 仓库** 并要复现

在仓库根目录 `Vnpy_Yue` 下执行（CSV 可用仓库内原路径，也可用本包内拷贝路径）：

```text
python examples/quick_tests/qmt_batch_hot_rank_backtest.py ^
  --rank-csv examples/quick_tests/策略热股5分钟-20260424_20260507/测试成分股/ths_hot_top100_20260424_20260507.csv ^
  --last-n-sessions 10 --top 100
```

（若把整个 `examples/quick_tests` 放在 PYTHONPATH 且脚本路径正确，也可把 `--rank-csv` 指到解压后的 CSV **绝对路径**。）

生成 **整体展示与打分**（推荐指向本包 **`产物/`** 下「无日线」xlsx，并把 md 一并打包）：

```text
python examples/quick_tests/策略热股5分钟-20260424_20260507/整体策略分析与打分.py ^
  --batch-xlsx examples/quick_tests/策略热股5分钟-20260424_20260507/产物/策略热股5m交付_THS20260424-0707_无日线_Top100_20260507_233707.xlsx
```
